# CAPUSCAST-BROADCASTING-CAMPUS-UPDATES-DIGITALLY

Broadcasting Campus Updates Digitally

CAPUSCAST is a web-based platform designed to broadcast campus updates, events, notices, and announcements in a structured and accessible manner for students and administrators.

Features
User authentication with secure login for students and administrators
Dashboard to view latest campus updates and announcements
Event management system to browse and view event details
Admin panel to create, update, and delete notices and events
Category-based filtering (events, holidays, alerts, etc.)
Email notification system for broadcasting updates
Responsive design for mobile, tablet, and desktop devices
Tech Stack

Frontend:

HTML
CSS
JavaScript
